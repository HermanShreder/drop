01 / OVERVIEW

Airdrop EKIDEN
для участников сообщества.

Здесь собрана вся ключевая информация о кампании: условия участия, порядок проверки кошелька, распределение и следующие шаги.

01

Что такое Airdrop

EKIDEN распределяет часть токенов среди подходящих участников. Чтобы попасть в список, сначала нужно пройти проверку кошелька.

02

Условие участия

Для участия нужен публичный адрес в сети TRON с минимум 50 USDT в официальном USDT TRC-20. Эти 50 USDT не нужно отправлять — их достаточно удерживать на своем кошельке.

03

Награда

После успешной проверки кошелек попадает в процесс распределения. Дальше остается ожидать начисления Airdrop.

02 / ABOUT THE DROP

Что нужно знать
об EKIDEN Airdrop.

Главная задача кампании — определить кошельки, которые соответствуют условиям, и подготовить их к распределению токенов.

TOKEN AIRDROP

Участие начинается с проверки кошелька

Проверка не списывает средства и не требует подписи транзакции. Сайт читает только публичный баланс USDT в сети TRON. Для участия 50 USDT достаточно просто удерживать на своем кошельке.

TRON Mainnet USDT TRC-20 минимум 50 USDT
01

Проверьте кошелек

После успешной проверки используйте только Trust Wallet. Никакие переводы USDT для участия не требуются.

02

Пройдите проверку

Система проверит официальный USDT TRC-20 и определит, есть ли на адресе минимум 50 USDT.

03

Ожидайте Airdrop

Если условия выполнены, ничего отправлять не нужно. Удерживайте 50 USDT на своем кошельке и ожидайте распределение токенов.

Дата распределения токенов

Точную дату распределения токенов опубликуем 4 октября 2026 года на официальном сайте. Следите за новостями и обновлениями.

Важно: для проверки никогда не вводите seed phrase/private key и не подписывайте перевод USDT. Проверка баланса выполняется в режиме read-only.
